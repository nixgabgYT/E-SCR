Easy Script (.escr)

Lightweight Windows scripting language built for automation, terminal utilities and system management.

01. Syntax Rules

// Comment
Everything beginning with // is ignored by the interpreter.
end
Stops script execution.

02. UI & Terminal

say("Hello")
Prints text to the console.
clear
Clears the console.
pause
Waits until the user presses a key.
beep
Plays the default Windows beep.
theme("orange")
Changes the console color.

orange • green • blue • white

03. System Information

sysinfo
Displays operating system information.
date
Shows today's date.
time
Displays the current system time.
uptime
Shows how long Windows has been running.
myip
Displays the local IPv4 address.
macaddress
Lists MAC addresses.

04. File Management

list files
Lists every file in the current directory.
list folders
Lists every folder in the current directory.
create folder("Demo")
Creates a new folder.
delete file("example.txt")
Deletes the selected file.
if file[*] number[5]
Checks whether exactly five files exist.

05. Network

myip
Displays the local IPv4 address.
macaddress
Lists every detected MAC address.
ping server
Pings the configured local server.

06. Power Commands

pc shutdown
Schedules a Windows shutdown after 60 seconds.
pc abort
Cancels a scheduled shutdown.
end
Ends the currently running script.

07. Timing

wait[1]
Pauses the script for one second.
wait[5]
Pauses the script for five seconds.
pause
Waits until the user presses a key.

08. Console Themes

theme("orange")
Applies the orange terminal theme.
theme("green")
Applies the green terminal theme.
theme("blue")
Applies the blue terminal theme.
theme("white")
Restores the default console colors.
